# Leave Management System

A web-based Leave Management System with Student and Authority login.

## 🌐 Live Demo

[Click here to view Leave Management System]( https://leave-management-system-1-ljsr.onrender.com)

## Features
- Student Login
- Authority Login
- Apply for Leave
- Approve or Reject Leave
- Track Leave Status

## Technologies Used
- HTML, CSS, JavaScript
- Node.js and Express.js
- MongoDB
